Google Analytics Integration

Track user behavior and website performance with Google Analytics

Setup Instructions

1

Create a Google Analytics Account

Visit analytics.google.com and sign up for a Google Analytics account if you don't already have one.

2

Set Up a Property

Create a new property for your website and select "Web" as the platform.

3

Get Your Measurement ID

After setting up your property, you'll receive a Measurement ID (starts with "G-").

4

Add the Tracking Code

Add the following attribute to your <body> tag:

<body data-analytics-id="G-XXXXXXXXXX">

Replace G-XXXXXXXXXX with your actual Measurement ID.

5

Verify Installation

Use the Google Analytics Real-Time reports to verify that your tracking is working correctly.

Advanced Tracking Features

Leverage our custom tracking implementation for deeper insights

Event Tracking

Track user interactions like button clicks, form submissions, and video plays.

ElevateAnalytics.trackEvent( 'Category', 'Action', 'Label', Value );

Conversion Tracking

Measure when users complete important actions on your site.

ElevateAnalytics.trackConversion( 'Purchase', 1299.99, 'USD' );

Scroll & Time Tracking

Automatically track how far users scroll and how long they stay on pages.

Our script automatically tracks:

  • Scroll depths (25%, 50%, 75%, 90%)
  • Time on page (30s, 1m, 2m, 3m, 5m)
