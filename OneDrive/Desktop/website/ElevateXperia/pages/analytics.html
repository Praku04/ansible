Google Analytics Setup Guide

Follow these steps to set up Google Analytics for your ElevateXperia website:

  1. Create a Google Analytics Account

    If you don't already have one, go to analytics.google.com and sign up for a Google Analytics account using your Google account.

  2. Set Up a Property

    Create a new property for your ElevateXperia website. Select "Web" as the platform and enter your website URL.

  3. Get Your Tracking ID

    After creating your property, you'll receive a tracking ID (UA-XXXXXXXX-X) or a Measurement ID (G-XXXXXXXXXX) if you're using Google Analytics 4.

  4. Add the Tracking Code to Your Website

    Copy the tracking code provided by Google Analytics and add it to your website's HTML. Place the code just before the closing tag on every page you want to track.

    <script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script> <script> window.dataLayer = window.dataLayer || []; function gtag(){dataLayer.push(arguments);} gtag('js', new Date()); gtag('config', 'G-XXXXXXXXXX'); </script>

    Replace G-XXXXXXXXXX with your actual Measurement ID.

  5. Set Up Goals and Conversions

    Configure goals in Google Analytics to track important actions on your website, such as:

    • Tour bookings
    • Contact form submissions
    • Newsletter sign-ups
    • PDF downloads
  6. Verify Installation

    Use the Google Analytics real-time reports to verify that your tracking code is working correctly. Visit your website and check if your visit appears in the real-time reports.

Need help? If you need assistance setting up Google Analytics for your ElevateXperia website, please contact our technical support team.
